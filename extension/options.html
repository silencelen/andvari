This server can't be used

This browser gives andvari no storage of its own in this mode (Firefox does this when it never remembers history), so andvari can't keep a server choice here, and signs in nowhere. Nor can it keep the vault open while idle: the vault locks whenever Firefox pauses andvari, and quick unlock is off.

To use your own server, enter its address (for example https://andvari.example.com) and continue. andvari checks the server's identity card before you decide.

Autofill injection: …

andvari never asks for your master password or PIN on a web page — only in this options tab and the toolbar popup. The address above is the exact origin this browser will connect to.

Appearance

"Match my device" follows your device's light/dark setting. Picking Light or Dark keeps the andvari extension that way in this browser — the popup, this page and the quick-unlock window. The web vault keeps its own setting.

Remove data for this server

Delete this browser's stored PIN / quick-unlock and cached state for the server shown above. Your encrypted vault on the server is not affected. Use this before handing off the machine, or to clear a server you no longer use.
