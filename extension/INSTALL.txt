andvari browser extension — manual install (sideload)
=====================================================

Most people should NOT use this file. There are two easier, auto-updating
ways to install andvari, both linked from your andvari server's web vault
under Settings > Devices:

  * Chrome / Edge / Brave — the Chrome Web Store listing (unlisted, so it
    is install-by-link; the Devices page has the link).
  * Firefox — a Mozilla-signed .xpi. Click it and Firefox installs it, and
    it updates itself from then on.

Sideloading from disk, below, is for development or for when you cannot use
either of those. It does not auto-update.

Before you start: the extension comes preconfigured for the server at
andvari.monahanhosting.com and reaches it from any network. If you run your
own andvari server, point the extension at it in the extension's Options
page after installing.

Keep the unzipped folder somewhere permanent (e.g. Documents\andvari-extension).
The browser loads the extension FROM that folder — if you delete or move it,
the extension breaks.

Chrome / Edge / Brave
---------------------
1. Unzip this file to a permanent folder.
2. Open the extensions page:
     Chrome: chrome://extensions    Brave: brave://extensions    Edge: edge://extensions
3. Turn ON "Developer mode" (toggle in the top-right corner; in Edge it's
   in the left sidebar).
4. Click "Load unpacked" and pick the unzipped folder.
5. Pin andvari (puzzle-piece icon > pin), click it, and sign in with your
   email + master password. Unlocking takes a few seconds - that is the
   key-stretching doing its job.

Firefox
-------
Prefer the signed .xpi (see the top of this file). Firefox keeps an UNSIGNED
extension loaded only until you close the browser, so the steps below are a
development loop, not an install:
1. Unzip this file.
2. Go to about:debugging#/runtime/this-firefox
3. Click "Load Temporary Add-on..." and pick manifest.json inside the folder.
4. Firefox treats site access as optional: open the extension's entry under
   about:addons > Permissions and enable "Access your data for" your andvari
   server (and "all websites" if you want autofill) — without it, sign-in
   reports the server as unreachable.
5. After restarting Firefox you'll need to repeat steps 2-4.

Updating (already installed this way?)
--------------------------------------
1. Download the new zip and unzip it OVER the same folder you used before
   (replace everything).
2. Open the extensions page and click the reload (circular arrow) icon on
   the andvari card. Firefox: redo the temporary load.
3. Reload any open tabs you want andvari active in.

Using it
--------
- Just installed or updated? Reload any tabs that were already open — the
  page part of andvari loads with the page.
- Click into a username or password field on a login page: a small andvari
  dropdown lists your matching logins; click one to fill both fields.
- Submit a login the extension doesn't know: a "Save to andvari?" bar
  appears at the top of the page.
- The toolbar popup shows lock status; "Lock" wipes the keys from memory.
- No vault secrets are written to disk - closing the browser locks it.

Problems? Report them on the project's GitHub repo
(https://github.com/silencelen/andvari), or to whoever runs your andvari
server. Note the site and what you expected to happen.
